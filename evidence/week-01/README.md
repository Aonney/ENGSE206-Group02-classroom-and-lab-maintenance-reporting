## 3. Findings

จากการวิเคราะห์ปัญหาใน Week 01 พบประเด็นสำคัญดังนี้

1. การแจ้งปัญหายังเกิดขึ้นผ่านหลายช่องทาง
2. ข้อมูลที่ใช้ในการดำเนินงานอาจไม่ครบถ้วน
3. เจ้าหน้าที่ต้องใช้เวลาในการสอบถามข้อมูลเพิ่มเติม
4. มีความเสี่ยงที่จะเกิดการแจ้งปัญหาซ้ำ
5. ผู้ใช้งานไม่ทราบสถานะหรือความคืบหน้าของงาน
6. งานบางรายการต้องมีการส่งต่อระหว่างหน่วยงาน
7. งานที่กระทบต่อการเรียนการสอนอาจต้องมีการจัดลำดับความสำคัญ
